# @KakoolNews Telegram MTProto Proxy

Free Telegram proxy powered by GitHub Codespaces.

## Quick Start

1. Click "Code" → "Create Codespace"
2. Wait for setup to complete
3. Copy the proxy link and import in Telegram

## Proxy Link

```
tg://proxy?server=<codespace>-443.app.github.dev&port=443&secret=<generated>
```

## Features

- Auto-generated secret
- Runs on port 443
- Free on GitHub Codespaces
